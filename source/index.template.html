A SHORT FIELD GUIDE

When symptoms form a system.

A symptom can be both a consequence and a cause. Sleep problems can contribute to fatigue; fatigue can feed other difficulties. Strong feedback can keep a network active after its original trigger has gone.

01

Change a state

A node intervention changes a symptom’s current state once: off in Ising, or a reduction of 25 percentage points in the continuous model (stopping at 10%). Its field and connections stay the same, and it can rise again as the network evolves.

02

Change a disposition

A field intervention lowers τᵢ by 1.5 in Ising, or βᵢ by 0.25 in symptom dynamics, for the rest of the round. It reduces the tendency to activate, without forcing the current state to change. You can apply it more than once.

03

Change a connection

An edge intervention sets one interaction weight to zero for the rest of the round. In Ising it removes both directions; in symptom dynamics it removes only the selected arrow. Other paths remain.

What counts as a win?

Use at most six coins to get all nine nodes green at the same time and earn the Loop Breaker award. In Ising, green means off. In symptom dynamics, green means intensity ≤ 10%; this display band is a game choice because noisy continuous values rarely equal exactly zero. This is not a clinical recovery criterion.

In symptom dynamics, all four interventions cost 1 coin each: node, self-feedback, field and directed edge. In Ising, node switches cost 1 coin, field shifts cost 2 coins and symmetric edge removals cost 3 coins. Forecasts and undo each cost 1 coin. Undo restores the last action, including the clock and random sequence in the continuous model. Earlier spending stays spent. No undo is available at zero coins; an unsuccessful final response opens Play again automatically.

Ising: each treatment is followed by up to two sweeps. A sweep is nine random single-node updates with replacement. The game checks for all green immediately after intervention and after each sweep. A paid forecast calculates the exact all-off probability after six sweeps by enumerating 512 states.

Self-feedback: each continuous-model node has a visible loop, initially αᵢᵢ = 0.30 (Park et al., Table 3, base setting). For 1 coin, lower one loop to 0.10 for the rest of the round. This is the self-feedback value in the paper’s high-resilience setting; the intervention changes only that coefficient, leaving the boost factor and all other parameters unchanged. It does not reset intensity and cannot be stacked on an already lowered loop. Choose the card and a node, or click its loop. Dashed loops have been lowered. A forecast can preview this intervention; undo restores the loop.

Symptom dynamics: intensity follows the continuous-time model of Park, Waldorp & Vasconcelos (2026). A treatment is followed by up to 20 model-time units, with gradual colours, percentage levels, and a live clock. Pause freezes the playback; Resume continues the same response. Time pauses between moves. Watch +10 advances 10 units with no treatment or coin charge. The game checks all green at each numerical step and stops at the first success.

Its paid forecast estimates the chance of all nine intensities being ≤ 10% at 40 model-time units, using 256 simulated paths per scenario; it also shows expected average intensity. This is an approximate fixed-horizon forecast, not an exact probability or the chance of winning earlier. Zero successes means 0/256, not proof of impossibility. Separate random sequences keep buying a tip from changing the round. A new treatment or passage of time clears current tips.

Both models are stochastic. Restart reuses the same random sequence to compare strategies. Time units are dimensionless, not calibrated days. Parameters, treatment doses and game rules are illustrative, not fitted to an individual.

The Ising model

In Ising mode, we use a 0/1-coded model. For the selected node i, the probability of being active on its next update is:

pᵢ = 1 / [1 + exp(−(τᵢ + Σⱼ wᵢⱼ xⱼ))]

Lowering τᵢ reduces activation, matching the NIRA activation-parameter convention. Each update chooses one node uniformly at random. This single-site Gibbs rule has stationary probability:

P(x) ∝ exp(Σᵢ τᵢ xᵢ + Σᵢ<ⱼ wᵢⱼ xᵢ xⱼ)

With nine binary nodes there are 512 states. We propagate probability across all states for 54 updates to calculate the six-sweep outlook exactly. A node intervention moves the current state only; an edge or field intervention changes the transition probabilities.

This is inspired by Cramer et al.’s dynamic framework, using asynchronous updates consistent with the joint Ising distribution rather than reproducing their synchronous update rule. The supplied Epskamp chapter uses −1/+1 coding in Equation 8; our parameters are defined directly in 0/1 coding and are not copied across conventions.

The continuous-time model

Park, Waldorp & Vasconcelos (2026), Equation 2, with f(s) = s²:

dsᵢ = sᵢ(1 − sᵢ)[βᵢ + αᵢᵢsᵢ + (1 + δᵢsᵢ²) Σⱼ≠ᵢ αⱼᵢsⱼ] dt + σᵢ dWᵢ

Arrows show source → target influences from Appendix A4. Self-feedback αᵢᵢ = 0.30 is shown as a loop at each node, with a 1-coin intervention to lower one coefficient to 0.10; δᵢ = 9.50 is the base setting in Table 3. Baseline β uses the normal-period values in Table 2. Independent additive Gaussian noise and reflecting boundaries keep intensities between 0 and 1. The simulation uses Euler–Maruyama integration with Δt = 0.02.

For this game we choose an initial intensity of 0.92, noise strength σ = 0.10, a field reduction of 0.25, and a green band at ≤ 0.10. A one-time node intervention subtracts 0.25 from intensity, with a floor of 0.10; for example, 0.90 becomes 0.65. It does not guarantee a green node. These are game settings, rather than a reproduction of the paper’s shock experiment. Intensities can recover or rebound; there is no imposed decay. Directed coupling makes this a different model from the Ising network. Its forecasts are simulation estimates and do not use the Ising equilibrium formula.
